## Nombre del proyecto : VIAJAPERU
## Objetivo
Desarrollar un sistema básico de registro y gestión de vuelos aéreos,
aplicando control de versiones colaborativo con GitHub.

## Integrantes

## Descripción
El sistema permite registrar vuelos, consultar su estado en tiempo real,
actualizar informacion de itinerarios y generar reportes de pasajeros
por ruta. Cada modulo fue desarrollado por un integrante del equipo en
una rama independiente.
